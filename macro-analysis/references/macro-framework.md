# 宏观分析框架

## 关键指标解读

### 增长类指标

| 指标 | 解读逻辑 | 敏感资产 |
|---|---|---|
| GDP | 环比增速。>3% 过热，<1% 衰退预警 | SPY, QQQ, IWM |
| PMI (制造业/服务业) | 50 为荣枯线。连续 <48 预示衰退 | XLI, XLF |
| 非农就业 | >200K 过热，<100K 疲软。关注时薪增速 | USD, TLT, GLD |
| 零售销售 | 消费占 GDP 70%。连续负增长 = 衰退信号 | XLY, XRT |
| 消费者信心 | 领先指标。大幅下滑预示消费收缩 | SPY |

### 通胀类指标

| 指标 | 解读逻辑 | 敏感资产 |
|---|---|---|
| CPI (核心) | >0.3% MoM 引发加息担忧。关注住房和超级核心 | QQQ, TLT |
| PCE (核心) | 美联储首选通胀指标。2% 为目标 | QQQ, GLD |
| PPI | CPI 的领先指标。PPI 先行上涨会传导到 CPI | SPY |
| 时薪增速 | 工资-通胀螺旋的关键。>0.4% MoM 是警报 | TLT, USD |

### 央行政策

| 事件 | 关注点 | 敏感资产 |
|---|---|---|
| FOMC 会议 | 利率决议 + 点阵图 + Powell 发布会。每个词都被市场解读 | 全资产 |
| 会议纪要 | 3周后公布。关注内部分歧程度 | SPY, QQQ |
| 央行官员讲话 | 投票委员 > 非投票委员。鹰派 = 利好 USD，鸽派 = 利好股市 | USD, SPY |
| 缩表 (QT) | 关注资产负债表缩减节奏是否调整 | TLT, QQQ |

## 传导机制

### 利率传导链

```
FOMC 加息 → 短端利率↑ → 融资成本↑ → 成长股估值压缩 → QQQ↓
                                    → 企业 capex 下降 → 周期性板块承压
                                    → USD↑ → 新兴市场资金外流 → EEM↓
```

### 油价传导链

```
地缘政治 → 原油供应中断 → 布油↑ → 通胀预期↑ → FOMC 偏鹰 → 股市承压
                              → 能源股↑ (XLE) → 航空/运输↓ (JETS, IYT)
                              → 消费支出被挤压 → 零售股↓
```

### 避险传导链

```
VIX 飙升 (>25) → Risk-off → 资金流向: GLD↑, USD↑, TLT↑, BTC↓
                           → 高 Beta 股领跌 (ARKK, IWM)
                           → 防御性板块跑赢 (XLP, XLV, XLU)
```

## 历 Reference 节奏

### 季度模式（以美国为中心）

| 时间 | 事件 | 策略调整 |
|---|---|---|
| 1月 | Q4 财报季启动 + 全年指引 | 关注银行股打头阵（JPM, GS），科技股后续 |
| 3月 | FOMC 季度 SEP（经济预测摘要） | 点阵图最关键，决定全年利率路径 |
| 4月 | Q1 财报季 + 税季 | 关注 Q2 指引是否超预期 |
| 6月 | FOMC 季度 SEP + Russell 再平衡 | 小盘股流动性事件 |
| 7月 | Q2 财报季 | 关注下半年展望和 AI 投资回报 |
| 9月 | FOMC 季度 SEP + 财政年度末 | 历史上最波动的月份 |
| 10月 | Q3 财报季 | 关注假日季指引 |
| 12月 | FOMC 季度 SEP + 圣诞 Rally | 12/31 窗口粉饰 (window dressing) |

## 事件驱动评分

评估每个事件对市场的影响：

| 级别 | 说明 | 示例 |
|---|---|---|
| 🔴 5级 | 系统性风险，影响全资产 | FOMC 意外加息50bp、战争爆发 |
| 🟠 4级 | 板块级冲击，影响相关资产 | 油价暴涨10%+、科技巨头财报暴雷 |
| 🟡 3级 | 个股/行业级影响 | 单一公司财报、行业监管变化 |
| 🟢 2级 | 边缘影响 | 例行数据发布（符合预期） |
| ⚪ 1级 | 噪音 | 日常市场波动 |
